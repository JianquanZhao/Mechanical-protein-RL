# 力学蛋白强化学习项目阶段周报

**汇报周期：2026-07-20 至 2026-08-07**

## 一、整体研究计划

本项目拟建立“蛋白序列与结构表征、突变策略搜索、结构松弛、力学性能评价”一体化的强化学习框架。ESM2 提供变长序列的逐残基状态表征，DDQN 输出残基—氨基酸动作的 Q 值，PyRosetta 完成突变后的局部 repack，结构拓扑与氢键随机森林预测器提供终端力学 reward。当前重点已由单独验证力学预测器，转向检验 reward 能否稳定驱动策略学习，并解决全数据训练中的数值稳定性和采样吞吐问题。

## 二、当前阶段与本阶段工作

### 1. 基于结构的力学性能 reward 接入

完成 terminal reward 与 RL 主训练链路的整合。基础版本中，strength 与 toughness 权重设为 1:1；存在序列预测结构时，PyRosetta terminal packed structure 与预测结构的评分按 1:1 平均，缺失预测结构时回退到 PyRosetta 结构。step reward 的碰撞、主链氢键、侧链氢键和局部 RMSD 均映射至 0–1 后取加权平均，避免 Rosetta 能量项主导优化。

数据集划分得到 7,701 个训练结构和 856 个验证结构。32-episode ESM2 混合长度 smoke test 覆盖 36–290 aa、18 种长度，训练过程保持有限数值；loss 由 0.3375 降至 0.1341，平均绝对 TD error 由 0.7201 降至 0.4531，验证了 ESM2 per-residue 编码、变长 replay、DDQN Q head 与 terminal reward 的完整连通性。

### 2. 长时训练稳定性与更新频率分析

全量训练暴露出 Q value、TD error、loss 和 grad norm 先升高后降低的问题。将 episode horizon 从 1,024 降至 50、再降至 24 后，峰值降低且回落更快，说明长 horizon、持续正 step reward 和 bootstrap 共同放大了 Q 目标。进一步发现策略在低 epsilon 阶段存在大量重复修改和反向突变，且 Q 值明显高于实际 episode return，当前下降趋势只能说明数值恢复，不能等价为策略有效收敛。

训练代码新增独立的 `--train-frequency F` 与 `--gradient-steps G`，完成 F1/G1、F4/G1、F8/G1 对照。较高 F/G 可降低单位 transition 的更新强度并缓解峰值，但早期非有限值主要由混合精度前向误差触发；关闭 AMP 后 FP32 训练可继续运行。当前判断是：峰值不必机械地消除，但必须通过固定验证集、Q 与 Monte Carlo return 校准以及 terminal strength/toughness 改善来判断其是否可接受。

### 3. 多卡与异步 actor-learner 加速

先实现 batch size 128 的四卡 Q-head 数据并行，确认原多卡方案只覆盖较轻的网络更新，最耗时的 PyRosetta 环境与逐步 ESM2 编码仍是串行瓶颈。随后在 `asynchronous` 分支实现集中式 actor-learner：CPU 上运行 12 个独立 PyRosetta actor，GPU 1–3 执行动态批量 ESM2 推理，GPU 0 负责 DDQN learner，并通过有界队列传递 embedding、transition 与策略快照。完整测试结果为 115 passed、3 skipped，真实双 GPU smoke test 可正常完成进程隔离、采样、优化、日志、checkpoint 和退出。

在相同 F8/G1、batch 128、max_steps 24 的稳态区间，异步方案原始吞吐为 8.55 step/s，串行为 3.02 step/s，端到端提升 2.83 倍；扣除两者不一致的 validation、绘图和大 replay checkpoint 后，核心流水线仍提升 2.29 倍。共同前 12,023 次更新中，异步 loss、TD error、Q value 峰值分别降至串行的 6.60%、6.76% 和 8.56%。主要原因是多 actor 交错采样显著降低 transition 时间相关性，独立轨迹扩大状态覆盖，策略滞后削弱即时正反馈；但 target sync 间隔不同仍是混杂变量。

## 三、相较上一阶段的变化

上一份周报的主要结论是：基于氢键和拓扑的随机森林在 SMD 同源数据中具有较强排序能力，但难以直接外推至 MechanoPro-DB 单分子实验或蛛丝材料层级。本阶段据此将预测器定位为结构层面的辅助力学 prior，并真正接入 RL terminal reward。研究目标由“预测器是否有效”推进到“该信号如何稳定参与策略学习”；方法由离线相关性评估扩展为变长 DDQN、长时训练对照和异步采样；结果上已跑通 reward 闭环并获得 2.29 倍核心吞吐提升，同时确认 Q 高估、重复动作和 predictor 层级外推仍是主要风险。结论是工程链路已具备开展系统实验的条件，但尚不能仅凭 loss 回落宣称获得了有效力学优化策略。

## 四、下一步计划

下一阶段首先进行严格消融：统一 target sync、validation、checkpoint 和环境步数，对比串行与异步以及不同 policy sync 间隔，分离采样去相关、target 更新和策略滞后的贡献。其次增加 Q-return 校准、重复位置动作屏蔽和固定验证集 terminal strength/toughness 统计。性能侧记录 ESM2 实际 batch size、等待时间、PyRosetta 时间、IPC 时间与 learner 占空比，并尝试按序列长度分桶和减少 embedding 跨进程复制。在稳定性与吞吐均确认后，再启动完整训练并以力学指标改善而非训练 loss 作为主要判据。
