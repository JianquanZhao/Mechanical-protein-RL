# 力学蛋白强化学习项目周报

## 一、整体研究计划

本项目的长期目标是构建一个面向力学蛋白优化的强化学习框架。
整体思路是：先用蛋白质语言模型和结构预测方法描述突变后的蛋白状态，
再通过 PyRosetta 或 ColabFold 得到局部或终端结构，
最后用力学性能预测器给出 reward，引导 DDQN agent 搜索更优突变序列。

目前项目已经不再只停留在 RL 代码框架层面，
而是进入了 reward 是否科学可靠的验证阶段。
由于力学性能本身跨越了单分子结构、SMD 模拟和宏观材料性能三个层级，
本周工作的重点是判断我们当前基于结构拓扑和氢键网络的力学性能预测器，
到底适合用于什么层级的筛选任务。

## 二、当前阶段

当前已经完成一个基于 7 个结构特征的统计机器学习预测器。
输入特征包括序列长度、单位残基氢键数量、非局部氢键密度、
强非局部氢键比例、强非局部氢键密度、非局部主链-主链氢键密度和氢键 contact order。
模型采用 random forest，同时预测 SMD 数据中的 toughness `v127` 和 strength `v128`。

在同源数据集测试中，该方法表现较好。
以随机划分测试集为例，toughness 的 R2 约为 0.66，
Spearman 约为 0.89；strength 的 R2 约为 0.30，
Spearman 约为 0.83。
这说明氢键网络和结构拓扑确实包含较强的 SMD 力学解释信号。

## 三、本周工作内容

### 1. 完成终端 reward 的结构化封装

本周继续完善了 terminal reward 的使用方式。
基于 `params/hbond_random_forest.joblib`，在 `model/reward_module/terminal_reward`
中封装了结构特征提取、模型加载、物理量预测和 reward 标量化流程。
该模块可以对 PyRosetta relaxed 结构或 ColabFold predicted structure 进行打分，
并返回 strength、toughness、normalized reward、结构质量和氢键特征诊断信息。

这一步的意义是把前期统计模型真正接入 RL 系统，
使其从离线分析模型变成可调用的 terminal reward 组件。

### 2. 测试序列-预测结构-性能预测流程

我们使用 ColabFold no-MSA + Amber relax 跑通了
“蛋白序列 -> 预测结构 -> 结构特征 -> 力学性能预测”的完整流程。
在 CATH/SMD 测试集上，使用真实结构时模型效果较好；
使用 ColabFold 预测结构时，R2 明显下降，
但排序相关性仍然保留了一部分信号。

在 705 个 CATH 测试样本中，ColabFold predicted structure 下：
toughness Spearman 约为 0.74，strength Spearman 约为 0.82。
这说明预测结构会引入误差，但并不会完全破坏排序信号。

![CATH predicted structure evaluation](output/evaluate-mechanical-predictor/figures/cath_test_groundtruth_vs_predicted_scatter.png)

### 3. 在 MechanoPro-DB 上做外部实验数据验证

我们进一步使用 MechanoPro-DB 做第三方数据集验证。
该数据集记录的是单分子实验中的 unfolding/clamp force，
和我们训练模型使用的 SMD `v127/v128` 并不是完全相同的物理量。

结果显示，MechanoPro-DB 上整体相关性较差。
在 38 个聚合 PDB entry 中，ColabFold predicted structure 下，
toughness、strength 和 terminal reward 与实验断裂拉力的 Spearman
均为负值，约为 -0.37 到 -0.39。
top-k 分析也显示当前模型不能稳定富集实验高拉力蛋白。

![MechanoPro top-k](output/evaluate-mechanical-predictor/compared_based_predicted-MechanoPro-DB/figures/mechanopro_topk_enrichment.png)

这个结果并不意味着 SMD predictor 失败。
更合理的解释是：MechanoPro-DB 是单分子实验数据，
受加载方式、实验室差异、构建体边界、重复测量和实验误差影响很大；
而当前模型学习的是 SMD 数据中的结构-力学关系。
因此 MechanoPro-DB 更适合作为外部压力测试，
不适合作为当前 SMD reward 的直接验证集。

### 4. 在蛛丝材料数据库上验证材料层级相关性

本周还评估了 spider silkom database。
该数据库的标签不是单个蛋白的力学性能，
而是某一蜘蛛 taxon 产生的混合丝材料性能。
每个 taxon 可能包含多种丝蛋白类型，
因此我们先对每个蛋白结构打分，再聚合到 taxon 层级。

本次共解析 219 个 taxon，其中 204 个有材料性能标签；
成功评估 5,310 个唯一预测结构，
最终得到 203 个同时具有材料标签和结构预测的 taxon。
聚合方法包括 structure-weighted 和 type-balanced，
其中 type-balanced 更符合多种丝蛋白共同组成材料的假设。

结果显示，当前单蛋白 SMD predictor 与蛛丝材料性能的相关性很弱。
type-balanced 聚合下，材料 toughness 与预测 SMD toughness 的 Spearman
约为 -0.138；材料 tensile strength 与预测 SMD strength 的 Spearman
约为 -0.073。
top-10% 筛选中，terminal reward 对 toughness 有轻微富集，
但不足以支撑直接材料筛选。

![spider silkom scatter](output/evaluate-mechanical-predictor/evalutaed-spider_silkom/figures/spider_silkom_predicted_vs_material_scatter.png)

![spider silkom top-k](output/evaluate-mechanical-predictor/evalutaed-spider_silkom/figures/spider_silkom_topk_enrichment.png)

为了完成大规模结构评估，本周还优化了氢键提取代码。
原始氢键搜索在全量蛛丝结构上较慢，
现在改为使用 `scipy.spatial.cKDTree` 做空间索引，
保持原有氢键阈值和特征定义不变。
典型结构评估时间从约 1-3 秒降低到 0.2-0.3 秒，
16 个 worker 下整体速度约为 55 个结构/秒。

## 四、相较前期工作的变化

前期工作主要证明了：在 SMD 同源数据内部，
氢键网络和拓扑特征可以预测力学性能。
本周进一步回答了一个更关键的问题：
这个 predictor 能不能直接外推到实验单分子力学或蛛丝材料性能。

目前结论比较清楚：
该模型可以作为单蛋白结构层面的力学潜力 prior，
但不能直接作为实验断裂拉力或宏观材料性能 predictor。
不同层级之间存在明显物理差异：
SMD 标签描述的是模拟条件下的单结构力学响应；
MechanoPro-DB 描述的是单分子实验拉伸；
蛛丝数据库描述的是多蛋白混合、纤维组装和实验条件共同决定的材料性能。

因此，后续 reward 设计不能只依赖当前 terminal reward。
更稳妥的方案是把它作为辅助结构 reward，
再加入材料层级或实验层级的校准模型。

## 五、下周计划

下周建议围绕“层级建模”推进。
第一步，构建 spider silkom 的 taxon-level 模型，
把每个 taxon 的多蛋白结构评分、silk type composition、
氨基酸组成、poly-A、GPGXX motif、fragment count 和 total length 一起作为输入，
预测材料 toughness 和 tensile strength。

第二步，对 MechanoPro-DB 单分子数据补充 pulling geometry 或测量方式信息，
避免把不同实验条件下的断裂拉力直接混合。

第三步，在 RL reward 中保留当前结构 predictor，
但将其定位为结构稳定性和潜在力学增强的辅助项，
而不是最终唯一优化目标。
